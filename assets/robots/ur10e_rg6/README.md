# UR10e + RG6 composite

`ur10e_rg6.urdf` is generated by:

```bash
python scripts/build_ur10e_rg6_composite_urdf.py
```

The builder combines the project UR10e model with the validated OnRobot RG6
model through one fixed `flange -> RG6 base` joint. Isaac Sim then imports the
result as one fixed-base articulation rather than coupling two articulations
at runtime.

The mount transform is identity in the UR10e flange frame. The RG6 model's
positive Z axis therefore follows the flange/tool axis. This is a simulation
mount assumption and must be replaced by the measured lab adapter and hand-eye
calibration before real-robot transfer.
